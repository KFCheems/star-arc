# 上架清单 · Submission Guide

面向微信小游戏与抖音小游戏的后台提交材料。代码已经能跑，这份清单只解决"提交时填什么"。

---

## 一、基础信息（两个平台通用）

**游戏名称**：星弧

**一句话简介（≤ 30 字）**
> 按住环绕一颗星，松手疾行。在金色弧上脱手，就是完美。

**详细描述**
> 《星弧》是一个只用一根手指就能玩的轨道街机游戏。
>
> 按住屏幕，你会环绕离你最近的那颗星旋转；松开，你会沿切线飞出去，去抓住下一颗星。
> 每颗星的外圈都有一段金色圆弧，在它扫过你的位置时松手——这一下叫「完美脱手」，
> 你会飞得更快、震开身边的碎星，并把倍率推到更高。
>
> 但你永远不会被推着走。你可以一直握着一颗星，直到它的燃料烧尽；
> 也可以为了一个更漂亮的连击，冒险冲进更深的地方。撞到星场边界只是弹回来，
> 会让你失去连击——真正致命的只有碎星。所以每一次结束，都是你自己按下的。

**关键词**：轨道 / 街机 / 单指 / 休闲 / 连击 / 太空 / 极简 / 高分挑战

**适龄**：4+（无暴力、无文字聊天、无内购）
**分类**：休闲 · 街机
**支持方向**：仅竖屏

## 二、微信小游戏

| 项目 | 填写内容 |
| --- | --- |
| AppID | 你自己的小游戏 AppID（`dist/wechat/project.config.json` 中的 `appid`） |
| 类目 | 游戏 → 休闲游戏 |
| 服务类目资质 | 按微信要求，小游戏需提供《游戏版号》或走"无版号"备案流程；个人主体请确认当前政策 |
| 是否含内购 | 否 |
| 是否含广告 | 否（如需接入，`platform.js` 已留出扩展点） |
| 用户隐私保护指引 | 见下方「隐私」章节 |

**导入步骤**
1. 微信开发者工具 → 导入 → 小游戏
2. 目录：`dist/wechat`
3. AppID 填入后编译，真机预览确认手感

**分享**
`dist/wechat/share.png` 是 5:4 分享卡片（1000×800）。`game.js` 已调用
`wx.showShareMenu` 与 `wx.onShareAppMessage`，默认分享文案带当局分数。

## 四、商店素材

| 用途 | 文件 | 尺寸 |
| --- | --- | --- |
| 应用图标 | `assets/store/icon.png` | 1024×1024（另附 `icon-512.png`） |

后期碎星满场、结算页。

## 五、隐私

本游戏**不收集任何个人数据**：

- 无账号系统、无登录
- 无网络请求（`game.js` 完全离线）
- 无第三方 SDK
- 本地仅存 4 个键：最高分、静音状态、是否看过教程、累计局数
  （`stararc.best` / `stararc.mute` / `stararc.seen` / `stararc.runs` / `stararc.total`）

微信「用户隐私保护指引」可直接声明：不收集用户信息。

## 六、审核常见问题排查

| 症状 | 检查 |
| --- | --- |
| 白屏 | 确认导入的是 `dist/wechat`（含 `game.js` 与 `game.json`），不要直接导入仓库根目录 |
| 说缺少 game.json | 先跑 `npm run build` 生成 `dist/` |
| 触摸无反应 | 确认设备竖屏；`game.json` 已设 `deviceOrientation: portrait` |
| 横屏被拉伸 | 已处理：宽屏会居中显示竖版星场，两侧留黑 |
| 没有声音 | 首次触摸后才初始化音频（平台要求用户手势），属正常行为 |
